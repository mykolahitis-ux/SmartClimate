# SmartClimate

IoT-система моніторингу мікроклімату в аудиторіях університету.

Датчики температури, вологості та CO₂ на базі мікроконтролера ESP32 передають дані через протокол MQTT на хмарний бекенд, а результати відображаються у веб-панелі.

## Мета проєкту

Забезпечити дистанційний контроль температури, вологості та CO₂ в аудиторіях, дати персоналу змогу вчасно реагувати на відхилення та зібрати реальні дані пілотного впровадження у 2–3 аудиторіях.

## Архітектура

```
[ESP32 + датчики] --MQTT (TLS)--> [MQTT-брокер] --> [Бекенд: API + сховище] --> [Веб-панель]
```

| Модуль | Опис |
|--------|------|
| `firmware/` | Прошивка ESP32: зчитування датчиків, MQTT-клієнт, локальне буферування даних |
| `backend/` | MQTT-брокер, приймання даних, API та сховище |
| `dashboard/` | Веб-панель з графіками та поточними показниками |
| `docs/` | Документація, схеми, плани тестування |

## Технологічний стек

- **Пристрій:** ESP32, C++ / MicroPython, датчики температури, вологості та CO₂
- **Протокол:** MQTT з шифруванням TLS та автентифікацією пристроїв
- **Бекенд:** AWS IoT або Azure IoT (резервний варіант: Raspberry Pi з локальним MQTT-брокером)
- **Фронтенд:** веб-панель (HTML/JS)
- **Інструменти команди:** Git, GitHub, Jira, Confluence (простір SCLIM)
